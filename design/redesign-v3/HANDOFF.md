# Six in the TPK — Redesign v3 build handoff

Approved by Seth ("Yes, polish it and build it"), 2026-10-20. Target repo: `Dichotomyofcontrol/tpk-group-schedule` (Next.js).
Source of truth: the HTML mockups in this folder (`landing`, `signin`, `playdates`, `campaign`, `polls`, `invites`, plus `*-night` variants). `style.css` is the shared base; each page has its page CSS inline in a `<style>` tag (it's generated by `build.py` + `pages.py`). Screenshots: `shots/` (`*-390.png` iPhone fold, `*-390-full.png` full page, `*-1280.png` desktop).

## Non-negotiables (from Seth's feedback)
1. **Signed out: exactly ONE sign-in entry point.** The landing has only the hero button "Sign in with email". The header shows only the logo (no Sign in button). Tab bar is hidden when signed out. `/signin` has only the email form.
2. **Logo appears once per screen** (header only; no footer logo, no logo repeated inside cards).
3. **No emoji anywhere in navigation.** Use the SVG icons in `svg/`.
4. **No round wax-seal date circles.** Dates are typographic stacks (weekday / big numeral / month).
5. **Page titles never sit under the sticky header** (`h1.top >= header.bottom`). Header is `position:sticky`, not fixed-over-content.
6. **Cream is the default theme, even when the OS is in dark mode.** Night is opt-in only (account menu toggle), stored per user (`localStorage` + profile). Do NOT use `prefers-color-scheme` to switch.
7. All tap targets ≥ 44×44 px.

## Fonts (bundled, OFL)
`fonts/Fraunces-Variable.woff2`, `fonts/Fraunces-Italic-Variable.woff2`, `fonts/Inter-Variable.woff2` (Latin subset, variable axes kept), licenses `fonts/OFL-*.txt`. In Next.js use `next/font/local`:
```ts
export const fraunces = localFont({ src:[{path:'./fonts/Fraunces-Variable.woff2',style:'normal'},{path:'./fonts/Fraunces-Italic-Variable.woff2',style:'italic'}], variable:'--serif', display:'swap', weight:'100 900' })
export const inter = localFont({ src:'./fonts/Inter-Variable.woff2', variable:'--ui', display:'swap', weight:'100 900' })
```
Headings use `font-variation-settings:"opsz" 72,"SOFT" 30`; recap body uses `"opsz" 14`.

### Spacing — 8pt grid
4 (hairline gaps only), 8, 12 (tight lists), 16, 20 (page gutter mobile, card padding), 24, 32, 40 (desktop gutter), 48, 64. Max content width 1120px. Desktop 2-col grids: `1fr 320px` (Play dates, Polls), `1fr 360px` (Campaign), `1fr 1fr` (Invites).

### Radii
cards 20 · cover thumbs/inputs/options 12–14 · pills & buttons 999 · avatars 50% · portraits 14.

### Shadows
`--sh: 0 1px 0 rgba(255,255,255,.7) inset, 0 1px 2px rgba(60,40,20,.06), 0 8px 24px -12px rgba(60,40,20,.18)`; primary button `0 6px 16px -6px rgba(29,25,21,.5)`; menu popover `0 24px 64px -16px rgba(40,25,10,.45)`. Night: `0 12px 32px -12px rgba(0,0,0,.6)` + 4% white inset.

### Motion
- Default ease `cubic-bezier(.2,.8,.2,1)`, 200ms for cards/pills/toggles; buttons `:active { scale(.97) }`.
- Route changes: React `<ViewTransition>` crossfade 180ms; campaign card → campaign hero morph via shared `view-transition-name` on the cover.
- "I can't make it": the person's pill animates to `.out` (avatar desaturates 200ms, vermilion strike-through draws left→right 220ms), status count ticks.
- Ribbon: on first paint drops 8px→0 with 240ms ease-out.
- Cover art: optional 2-layer parallax (≤8px) on hero only.
- Everything wrapped in `@media (prefers-reduced-motion: no-preference)`.

## Components
- **Header** (`.hdr`): sticky, 56px + safe-area-top (68 desktop), glass bg, 0.5px bottom hairline. Left: mark + wordmark "Six *in the* TPK" (Fraunces 19px, "in the" italic ink2). Right (signed in): desktop pill nav + account button (avatar 36 + chevron, 44px hit). Signed out landing: transparent header over art, logo only.
- **Mark** (`svg/mark.svg`): d20 silhouette (hexagon + facets) in ink on paper, vermilion centre face with a "6". Min size 20px. Never paired with a heart.
- **Tab bar** (mobile <900): fixed bottom, 4 equal tabs, 49px min + `env(safe-area-inset-bottom)`, glass bg. Icon 24px stroke 1.5 (1.75 active), label below. Active = --ver. Badge: 16px vermilion pill top-right of icon. Hidden when signed out.
- **Buttons**: `pri` ink pill 48 (hero 56), `sec` paper pill w/ border, `ghost` text; `.sm` = 44 tall. Never two primaries in a view.
- **Bookmark ribbon** (`.ribbon`): 28×52, notched bottom (clip-path), dashed stitching, overhangs card top by 4px. Vermilion = "up next / needs you", gold = recap. Max one per card.
- **Cover** (`.cover`): SVG scene (see `svg/cover-*.svg`, generated by `cover()` in build.py): sky gradient → horizon glow, moon with radial falloff + light rays, 4 ridge layers with rim-light strokes, blurred haze bands between ridges, silhouette landmark (tower/ship/forest) with lit windows, fractal-noise grain. Bottom scrim `transparent 35% → rgba(12,10,8,.72)` for text. GMs can later upload their own image; keep the same scrim + aspect (16:9 hero, 1:1 thumbs).
- **Date block** (`.dt`): weekday (vermilion eyebrow) / numeral (Fraunces 40) / month (ink3). Never a circle.
- **Person pill** (`.pp`): 36 tall, avatar 28. `.out` = dashed border, grayscale avatar 45%, name strike-through in vermilion.
- **Avatar stack**: 26px, -8px overlap, 2px paper ring; out members at 40% grayscale.
- **Status** (`.status`): 6px dot + 12px semibold; moss = all in, vermilion = someone out.
- **Segmented control** (`.seg`): 44px items in a tinted capsule; active = paper + shadow.
- **Poll option** (`.opt`): 64px row, fill bar behind content proportional to votes, check circle (filled ink when mine), leading option tinted vermilion 8%.
- **Account menu**: popover 288px (desktop anchored under avatar; mobile same, could become sheet). Items 48px: Profile & characters, Calendar subscription, Notification emails, Night theme (switch, 44×26), Sign out (vermilion, last).
- **Input**: 52px (48 inline), 12 radius, --field bg, focus ring 4px ink 8%.

## Schedule view (multi-campaign, multi-month) — `schedule.html`, `schedule-night.html`
Added 2026-10-20 at Seth's request. Lives inside Play dates as a 2-option segmented control: **Up next** (`playdates.html`) | **Schedule**. Same route, `?view=schedule`.
- **Data in the mock** (realistic cadence): Ashes of Emberfall every other Friday 7:30 PM (Seth GMs; skips Jan 1), The Drowned Crown alternate Fridays 7 PM (skips Dec 25), Wildwood Oath first Sunday 2 PM. One poll placeholder: Sat Nov 7 "Arc two kickoff?" (tentative). You're marked out on Nov 20 and Dec 11. Range: today → +3 months (Oct 2026 – Jan 2027); infinite-scroll older/newer by month.
- **Campaign color** token per campaign (`--cc`): Emberfall #B4542C, Drowned Crown #3D6F74, Wildwood #5E7040. GMs pick from a curated set of 8 earthy hues; never pure primaries. In night theme, campaign-name text is brightened (`filter: brightness(1.6)`) for contrast; implement as a lighter per-campaign night token instead.
- **Filter chips**: `All` + one chip per campaign (32px circular cover thumb ringed in campaign color + name). 44px tall. Single-select; `All` selected = ink fill. Mobile: horizontal scroll with snap and right edge fade; desktop: wraps.
- **Month heading**: Fraunces 30/36 month name + italic year in ink3, session count right-aligned. Sticky under the header (`top: header height`) with a bg→transparent fade. Anchor id `m-YYYY-M`.
- **Session row** (`.ev`, card): 4px campaign-color left edge · date block (weekday + numeral, no month — the month heading carries it) · campaign name (12.5px semibold in campaign color) / session title (Fraunces 17) / time · place · right: 40px cover thumb + your status pill: `You're in` (moss tint), `You're out` (vermilion tint; title struck through in vermilion, numeral dimmed), `Tentative` (dashed). Tap → session detail. Poll placeholder rows are transparent with a dashed border and dashed color edge, no thumb, link to the poll.
- **Desktop month overview** (≥900px, right rail 320px, sticky top 92): 2×2 mini months (Mon-first), 22px cells. Session days are bold ink with 10×3px campaign-colored bars under the numeral (stacked side by side when 2 campaigns share a day; dashed bar for poll dates; 35% opacity when you're out). Today = 1.5px ink rounded-square outline (not a circle). Past days dimmed. Clicking a day scrolls the list to `#d-YYYY-MM-DD` (`scroll-margin-top: 140px`) and flashes the row (180ms paper2 highlight). Clicking the month name jumps to its heading. Legend below: campaign color · name · your role. Mini-grid cells are below 44px by design (desktop pointer only; the rail is hidden on mobile); keep focus rings and aria-labels like "Nov 13: The Drowned Crown".
